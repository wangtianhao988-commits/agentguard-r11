# AgentGuard R11 — AI Agent 运行时安全防护

**研究工作版，尚未全面达到比赛指标。项目开发目前暂停。**

面向 AI Agent 的资产盘点、供应链风险识别、运行时检测、工具调用阻断和证据审计。R11 增加实际本地模型提议与执行合同校验、严格 JSON 输入边界、可解释资产/行为图谱、跨会话数据流标签、快速语义筛选与任务复核、纯处理器源码证明，以及连接池与解析优化。

## 安装与可独立运行的测试

Python 3.12/3.13，建议单独创建虚拟环境：

```powershell
py -3.13 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
$env:PYTHONUTF8='1'
$env:PYTHONIOENCODING='utf-8'
.venv\Scripts\python tools/run_public_tests.py
```

测试按文件隔离运行。需要未公开官方靶场或完整审计日志的测试会明确跳过，数量和名称见运行结果；不会伪装成全部通过。`08_实验脚本/run_r11_tests.py` 对应完整私有工作副本，公开仓库缺少其全部靶场附件。

## 目录

- `track2/detector`：规则、知识图谱、数据流、执行合同和模型复核。
- `track2/collector`：原生/网关接入、阻断、日志和现场函数帧。
- `track2/inventory`：资产发现、源码分析和风险识别。
- `track2/tests`、`track2/eval`：单元回归与证据评分。
- `05_复现脚本`、`08_实验脚本`：部署及实验驱动。
- `01_交付文档`：技术说明、验收边界和未达标问题。
- `07_修复验证`：经过筛选的历史结果摘要，不是完整原始日志。

## 靶场与完整复现实验

本仓库不再分发未确认再分发许可证的比赛官方靶场、完整归档数据或私有运行日志。获授权的参赛者应从官方渠道自行领取靶场，按本地部署脚本要求放置于 `_scratch/competition/agentrange` 及 `06_赛题与第三方/官方靶场原包/agentrange`，并补齐相应实验数据。

部署脚本会操作指定的 `agentrange` Docker 项目，应在自有隔离环境使用；源码内的模拟凭据和测试参数不是生产配置。脚本中以历史版本命名的路径对应各自历史实验，不能直接当作当前公开仓库全部可用的证据。

默认包含体积较小的 MiniLM ONNX 模型与 R11 线性筛选参数。可选 Qwen3-4B 权重约 2.5 GB，不随仓库上传；固定来源和 SHA 校验见 `08_实验脚本/download_local_model_r11.py`。模型容器需要支持 NVIDIA GPU 的 Docker 环境。

公开版本复制清单见 `PUBLIC_SNAPSHOT_MANIFEST.json`。第三方材料及权利边界见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
